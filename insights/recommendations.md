## Key Recommendations

### 1. Strengthen Schedule Management
- Closely monitor the 38 projects classified as Delayed, At Risk, or On Hold.
- Require recovery plans for significantly overdue projects.
- Escalate persistent schedule issues through PMO governance.

### 2. Improve Risk & Issue Management
- Prioritise projects with high risk scores and multiple High/Critical issues.
- Review the 94 High/Critical issues regularly.
- Assign clear owners and target dates for risk mitigation and issue resolution.

### 3. Strengthen Financial Control
- Investigate the 38 projects currently over budget.
- Monitor budget, actual cost, and cost variance at project level.
- Separate completed-project financial performance from in-progress project spending.

### 4. Improve Resource Planning
- Review the 44 projects with resource utilisation above 100%.
- Rebalance resources where sustained over-allocation exists.
- Investigate significantly under-utilised project capacity.

### 5. Strengthen Project Portfolio Governance
- Review project performance using a combination of:
  - Schedule
  - Cost
  - Risk
  - Issues
  - Resource utilisation
- Use consistent portfolio reviews across project managers.

### 6. Maintain Data Quality
- Continue automated checks for project, risk, issue, financial, and resource data.
- Ensure project status, costs, risks, issues, and resource allocations are regularly updated.

## PMO Review Cycle

| Frequency | Key Focus |
| Weekly | High risks, critical issues, overdue projects, resource over-allocation |
| Monthly | Cost variance, project status, risks, issues, resource utilisation |
| Quarterly | Portfolio capacity, project pipeline, financial performance, recurring risks |

## Conclusion

The analysis shows that PMO performance should be assessed across delivery, financial, risk, issue, and resource indicators together. The Power BI dashboard provides a central reporting tool for identifying projects requiring further review, escalation, or corrective action.
